# 实验语料说明

实验运行时，在本目录下创建 `input` 子目录，并放入不少于 10 篇英文纯文本文档：

```text
data/input/document01.txt
data/input/document02.txt
...
data/input/document10.txt
```

本实验可使用 RFC Editor 发布的英文技术文档作为语料，例如 RFC 791、RFC 793、RFC 1122、RFC 2616、RFC 3986、RFC 5321、RFC 6749、RFC 7540、RFC 8446 和 RFC 9110。

如文档体积较大，可不将语料上传到 GitHub，只需在实验报告中说明文档来源，并保留本说明文件。
